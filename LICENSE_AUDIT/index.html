    License audit inventory

    This is a repository inventory prepared for the Apache-2.0 adoption. It is not legal advice, a complete software bill of materials, or a representation that all dependencies are license-compatible. License texts and obligations must be verified from the exact distribution that a release includes.

    First-party status

    The repository did not document a copyright holder when this audit was made. The root NOTICE therefore uses [COPYRIGHT HOLDER]; a maintainer must confirm the owner and replace that placeholder before publication. Git author names are not by themselves proof of copyright ownership or contribution authority.

    Repository-owned Python files under src/robot/ carry an Apache-2.0 SPDX identifier. This does not relicense vendored assets, external model files, or contributions whose authorization has not been established.

    Python dependencies

    The manifests name the components below but do not embed their license texts. The detected-license column is intentionally Not verified from this repository unless a local notice establishes it. Resolve each exact installed version against its upstream package metadata and license file before a release.

    Component group Components named in manifests Detected license Source Concern / follow-up

    Hardware and sensors smbus2, rpi-ws281x, pyserial, RPi.bme280, bmp280 Not verified from this repository pyproject.toml Verify optional-package licenses and any Raspberry Pi OS packages used in production.
    Web Flask, Flask-WTF, Werkzeug, waitress, qrcode and pinned transitive packages Not verified from this repository pyproject.toml, requirements-web.txt Generate a version-pinned dependency and license inventory for the release environment.

    Documentation mkdocs, mkdocs-material Not verified from this repository requirements-docs.txt Verify build-time package licenses and theme assets used in published documentation.

    Repository delivery boundaries

    • No package.json, platformio.ini, ESP32 firmware source, or Git submodule was present in this checkout at audit time.
    • The official ESP32 firmware is maintained at phosairobot/phos-esp32; firmware license and dependency review must occur in that source repository.
    • Python dependency ranges are not a release inventory. Before publishing a binary image, wheel, container, or installer, produce a locked inventory for that artifact and preserve required notices.
